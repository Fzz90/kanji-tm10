# Presentasi kanji 危

Versi online: [fzz90.github.io/kanji-tm10](https://fzz90.github.io/kanji-tm10/). Repository: [Fzz90/kanji-tm10](https://github.com/Fzz90/kanji-tm10). GitHub Pages menerbitkan cabang `main`, folder utama repository. `.nojekyll` mempertahankan situs statis tanpa pemrosesan Jekyll.

Buka `index.html` langsung di Chrome, Edge, atau Firefox. Tidak perlu instalasi, server, atau internet. Simpan folder `assets` bersama HTML, CSS, dan JavaScript.

- Panah kanan/kiri: pindah slide. Keyboard: ← / →, Page Up / Page Down, Home / End. Ponsel: usap horizontal.
- Slide menulis: animasi berulang, tombol Jeda animasi dan Ulangi. Jika sistem memakai reduced motion, animasi mulai dalam keadaan dijeda; pilih Putar animasi untuk menjalankannya.
- Tombol layar penuh di pojok kanan atas: masuk/keluar presentasi fullscreen. Esc untuk keluar. F11 juga tersedia di Chrome/Edge pada Windows.
- Ponsel: slide yang panjang dapat digulir vertikal.
- Furigana hanya ditampilkan pada slide reibun. Tabel jukugo memiliki kolom cara baca tersendiri.
- Slide reibun hanya memuat enam kalimat beserta terjemahannya, tanpa judul kosakata atau arti singkat per contoh. Ukuran teks dan tinggi tiga baris desktop diperbesar untuk mengisi area slide.
- Kosakata sasaran di dalam reibun dicetak tebal. Perpindahan slide memakai sapuan merah/arang sekitar 0,93 detik sesuai arah navigasi, diikuti kemunculan isi bertahap. Preferensi reduced motion menonaktifkan transisi bergerak.

## Isi

Enam slide: judul dan identitas, bacaan dan bushu, penulisan, tabel enam jukugo beserta cara baca dan artinya, enam reibun beserta terjemahan, lalu penutup "Terima Kasih". Tidak ada pagination atau cara mengingat.

## Sumber dan lisensi

- Bacaan, enam goresan, dan radical 卩: [Jisho / KANJIDIC2](https://jisho.org/search/%E5%8D%B1%20%23kanji), data EDRDG. Bacaan dan keenam kosakata juga diperiksa di [漢字ペディア, 危](https://www.kanjipedia.jp/kanji/0001181300), 日本漢字能力検定協会, bersumber dari 角川新字源. Contoh kalimat disusun untuk presentasi dan bukan kutipan kamus.
- Konteks reibun 危険: dampak karhutla terhadap kesehatan warga Kalimantan, mengacu pada [ANTARA, 21 Oktober 2026 — Kemenkes siapkan rumah oksigen](https://www.antaranews.com/berita/5802081/kemenkes-siapkan-477-rumah-oksigen-respons-dampak-karhutla). Kalimat Jepang adalah contoh asli untuk belajar, bukan terjemahan kutipan; tidak memuat angka korban atau luas kebakaran.
- Arti 危篤: [Jisho / JMdict](https://jisho.org/search/%E5%8D%B1%E7%AF%A4).
- Penjelas singkat 危ない dan 危険 pada tabel menunjukkan nuansa konteks: “tidak aman” dan “potensi celaka”. Keduanya tetap bersinonim; penjelas ini bukan pembagian makna yang mutlak. [Cambridge, 危ない](https://dictionary.cambridge.org/dictionary/japanese-english/%E5%8D%B1%E3%81%AA%E3%81%84) mencatat makna dangerous/risky dan sinonim 危険.
- Goresan: [KanjiVG, 05371.svg](https://github.com/KanjiVG/kanjivg/blob/master/kanji/05371.svg), copyright 2009–2011 Ulrich Apel. [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). SVG asli tersimpan dalam `assets/05371.svg`; adaptasi ilustrasi dan animasi goresannya tetap CC BY-SA 3.0. Atribusi juga terlihat pada slide menulis.

- Favicon 危: `assets/favicon.svg`, adaptasi path KanjiVG, Ulrich Apel, CC BY-SA 3.0.
- Reibun memakai futsūkei dengan ukuran teks lebih besar. Hanya kosakata sasaran beserta furigananya yang berwarna; teks lainnya hitam arang. Bidang tulis memiliki garis bantu tengah horizontal dan vertikal putus-putus.
